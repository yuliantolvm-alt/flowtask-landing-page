# FlowTask - SaaS Landing Page

A modern and responsive SaaS landing page built from scratch using HTML5, CSS3, and vanilla JavaScript.

## Live Demo

[View Live Website](#)

## Overview

FlowTask is a fictional project management platform designed for modern teams.

This project was created to demonstrate front-end development skills including responsive design, semantic HTML, CSS layouts, JavaScript interactions, accessibility, SEO fundamentals, and performance considerations.

## Features

- Responsive design
- Mobile navigation
- Interactive FAQ accordion
- Responsive pricing cards
- Smooth scrolling
- Semantic HTML5
- Accessibility considerations
- SEO-friendly structure
- CSS custom properties
- Mobile-first responsive behavior
- Dynamic copyright year

- HTML5
- CSS3
